Epic Arepa Challenge is a VR game where the goal is pretty simple: eat 50 arepas before the timer reaches zero.

You can grab the 3D arepas and bring them to your mouth. When an arepa gets close enough, it counts as eaten and the counter goes up.

There is also a Camera Mode, where you don't need a VR headset. The camera tracks your finger, and moving it in front of the camera lets you control the game.

Play

You can play the game directly in your browser:

https://yohan-xx.itch.io/epic-arepa-simulator

No installation is required.

How to play

VR Mode

1. Grab an arepa.
2. Bring it close to your mouth.
3. Keep eating until you reach 50 arepas or the timer runs out.

Camera Mode

1. Allow the game to use your camera.
2. Move your finger in front of the camera to control the game.
3. Eat 50 arepas before the timer reaches zero.

Setup
Just click the game that will redirect you to itch.io and press play 

Requirements

For the online version:

- A modern web browser.
- A camera for Camera Mode.
- A compatible VR headset for VR Mode.

The project was made with Godot 4.7


Running the project locally

If you want to run the project from the source code, install Godot V4.7, open the project, and run the main scene.

How it works

The main interaction is based on the distance between the arepa and the player's mouth. When an arepa gets close enough, the game detects it as being eaten and increases the counter.

The game has two different control systems. VR Mode uses VR controllers to interact with the arepas, while Camera Mode uses the camera to track the player's finger. Both modes use the same basic gameplay, so the goal stays the same even though the controls are different.

The game also has a Colombian theme, with PNG images of Shakira, Gabriel García Márquez, and the Colombian flag used throughout the game.
